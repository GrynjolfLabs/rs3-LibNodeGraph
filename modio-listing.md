<h2>LibNodeGraph</h2>
<p>LibNodeGraph is the graph engine Watchdog runs. An alert is a graph of nodes. This library keeps that graph in memory and runs it. It draws no window of its own.</p>

<h2>Data Protection</h2>
<p>LibNodeGraph keeps the graph in memory while it runs. It does not write that graph, and it does not send it anywhere. Watchdog is what saves the graph. This information is not transmitted outside of the plugin under any circumstances.</p>
